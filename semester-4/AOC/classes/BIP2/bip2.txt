Arquitetura e Organização do BIP II

- Inclui um registrador com dois bits de estado:
    - STATUS.Z (Zero): Resultado da última operação aritmética = 0
    - STATUS.N (Negative): Resultado da última operação aritmética < 0
Inclui duas classes adicionais de instrução:
   - Desvio incondicional: Muda o fluxo de execução do programa, atualizando o PC com o endereço de instrução especificado
    - Desvio condicional: Se a condição especificada for verdadeira, desvia para o endereço de instrução especificado


Conjunto de instruções BIP II

Instrução de desvio incondicional
---------------------------------------------------------------
Mnemônico   | Significado | Descrição
---------------------------------------------------------------
JMP         | Jump        | Desvia incondicionalmente

Instruções de desvio condicional
---------------------------------------------------------------
Mnemônico   | Significado              | Descrição
---------------------------------------------------------------
BEQ         | Branch on Equal          | Desvia se igual
BNE         | Branch on Not Equal      | Desvia se não igual
BGT         | Branch on Greater Than   | Desvia se maior que
BGE         | Branch on Greater or Eq. | Desvia se maior ou igual que
BLT         | Branch on Less Than      | Desvia se menor que
BLE         | Branch on Less or Equal  | Desvia se menor ou igual que

Instruções de desvio condicional devem ser precedidas por uma operação SUB ou SUBI sobre os operandos a serem comparados.
Exemplo:
1 LD A
2 SUBI 2
3 BLE addr

if (A>=B) {
  A = A + 1 // Bloco 1
}
// Bloco 2

    SUB B
    BLT L1
    LD A 
    ADDi 1
    STO A 
L1:
    HLT

  B = B+1; // Bloco 2
